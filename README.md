# 📝 Todo List (React + Vite)

Este é um projeto de estudo em **React** utilizando **Vite**.  
A ideia foi construir um **Todo List** simples, mas completo, com persistência no **LocalStorage** e design responsivo.

## 🚀 Funcionalidades

- Adicionar novos itens à lista
- Marcar itens como concluídos
- Excluir itens individualmente
- Excluir todos os itens de uma vez
- Persistência dos dados no **LocalStorage**
- Layout responsivo com `@media`

## 🛠️ Tecnologias usadas

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- CSS puro com responsividade
- LocalStorage para persistência
- Deploy com [GitHub Pages](https://pages.github.com/)
